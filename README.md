# Happy Friendship Day Website

A responsive and interactive Friendship Day memory website created to celebrate 20 years of friendship since school. The website includes a beautiful landing page, music, confetti animation, featured memories carousel, categorized photo gallery, emotional friendship message, and final credit section.

## Project Theme

**Twenty Years. One Bond.**

This project is designed as a digital memory scrapbook for a group of friends who have been together since school. It highlights old school memories, friendship moments, reunions, and the emotional journey of staying connected over the years.

## Features

- Beautiful Friendship Day landing screen
- Background music with play/pause control
- Confetti celebration animation
- Smooth navigation buttons
- Featured memories carousel
- Categorized photo gallery
  - Very Old School Pictures
  - Old Pictures
  - All Photos
- Lightbox image preview
- Responsive design for mobile, tablet, and desktop
- Elegant color palette and typography
- Final section with friendship message and designer credit
